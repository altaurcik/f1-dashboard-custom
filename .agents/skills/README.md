## Поиск

Нужен Python 3; внешних Python-пакетов для поиска не требуется.
Запуск из корня F1-проекта с полным путём к скрипту:

```powershell
$uiSkillPath = (Resolve-Path '.agents/skills/ui-ux-pro-max/scripts/search.py').Path
python "$uiSkillPath" "badge chip label wraps" --domain ux
python "$uiSkillPath" "client component" --stack nextjs
```

Если `python` недоступен, используй `python3`, `py -3` либо доступный Python 3 runtime.
В upstream-примерах указан CLAUDE_PLUGIN_ROOT; здесь используется локальный путь выше.
Для небольших исправлений выбирай конкретный domain/stack. Генерация design-system
применяется к новому экрану или согласованной задаче общего визуального направления;
сохранять её следует с явным `--output-dir` корня проекта, согласно SKILL.md.

Обновление версии — отдельная задача. Контрольная сумма SKILL.md в SOURCE.json
относится к содержимому с LF; при проверке CRLF нормализовать к LF.
