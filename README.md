# F1 Dashboard Custom

Standalone project based on the original `f1-dash` dashboard code, kept in a separate git repository.

Current stage:

- Original dashboard visual components are preserved.
- Left half of the screen is the full timing/driver list, including gaps, tires, DRS, lap times, sectors, and mini-sectors.
- Right top is the track map.
- Right bottom is Race Control and Team Radio.
- Track Violations and the original side navigation are removed from this custom dashboard view.
